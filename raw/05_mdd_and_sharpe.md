# 技術筆記 05：最大回撤（MDD）與夏普比率（Sharpe Ratio）的評估陷阱

## 1. 核心指標定義與數學原理
在量化回測體系中，評估策略好壞不能僅看總報酬率（Total Return），必須衡量承擔每單位風險所獲得的超額收益，以及資金承受極端衝擊時的耐受極限：

1. **夏普比率（Sharpe Ratio, SR）**：
   定義為策略超額報酬（高於無風險利率 $R_f$ 之部分）的期望值除以該超額報酬的標準差（波動率 $\sigma_p$）：
   $$SR = \frac{\mathbb{E}[R_p - R_f]}{\sigma_p}$$
   年化夏普比率通常乘上時間因子 $\sqrt{N}$（如日頻率乘上 $\sqrt{252}$）。夏普比率衡量的是承擔整體波動下的單位風險回報。
2. **最大回撤（Maximum Drawdown, MDD）**：
   定義為在特定評估區間內，淨值自歷史最高峰值（Peak）下跌至後續最低谷底（Trough）的最大百分比跌幅：
   $$MDD = \max_{t \in [0, T]} \left( \max_{\tau \in [0, t]} \frac{P_\tau - P_t}{P_\tau} \right)$$
   MDD 反映了投資者若在最不幸的最高點買入時，所可能面臨的最極端賬面虧損幅度。

## 3. 回測評估常見陷阱與盲點
1. **夏普比率的常態分佈假設崩潰**：
   夏普比率假設資產報酬率服從對稱常態分佈（Gaussian Distribution）。然而金融資產普遍具備肥尾（Fat Tails）與負偏態（Negative Skewness）特徵。某些策略（如賣出虛值選擇權、高息套利網格）平日看似波動極小、夏普比率高達 4.0 以上，但本質上是「在壓路機前撿硬幣」，一旦遇上極端行情便單日爆倉歸零。
2. **波動率懲罰上行收益（Upside Volatility Penalty）**：
   夏普比率的分母將向上暴漲的收益也視為風險標準差進行扣分。對動量或長波段趨勢策略而言，爆發性獲利反而會拉低夏普比率，導致評估失真。此時應輔以索提諾比率（Sortino Ratio），僅將下行標準差（Downside Deviation）列為風險。
3. **回撤持續期（Drawdown Duration）被忽視**：
   許多策略 MDD 雖然僅 15%，但深陷水下（Underwater）長達 3 年無法創出新高。實盤中極少有基金經理人或個人投資者能承受數年的資金凍結與心理折磨，策略往往在漫長橫盤中被迫提前終止。
4. **取樣頻率膨脹假象**：
   計算夏普比率時，若策略持倉資產具備流動性不足或價格人為平滑（Smoothed Returns，如私募不動產或冷門債券），時序自相關性（Serial Correlation）會顯著低估日收益波動率，使年化夏普比率被大幅虛增 30%～50%。

## 4. 全方位績效審查架構
- **卡瑪比率（Calmar Ratio）輔助檢驗**：計算年化報酬率與 MDD 之比值（$Calmar = \frac{CAGR}{MDD}$），檢驗獲利是否能有效覆蓋最大潛在虧損。
- **水下時間分析（Underwater Curve & Time to Recovery）**：不僅看最大跌幅數值，更要統計歷史最長回撤持續天數（Longest Drawdown Period）與平均恢復期。
- **條件風險價值（CVaR / Expected Shortfall）**：評估超出 VaR 門檻以外的極端尾部損失均值，以防禦黑天鵝事件帶來的破產危機。
